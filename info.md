# Saints du Jour

Intégration Home Assistant qui affiche le saint du jour et le saint de demain
selon le calendrier liturgique français.

## Installation HACS

1. Ajouter le dépôt personnalisé `https://github.com/XAV59213/saintdujour` (catégorie **Integration**).
2. **Télécharger** Saints du Jour dans HACS *avant* de redémarrer.
3. Redémarrer Home Assistant.
4. Ajouter l’intégration : Paramètres → Appareils & services → Ajouter une intégration → Saints du Jour.

Si le dépôt disparaît après un redémarrage, c’est que HACS n’avait pas encore téléchargé l’intégration. Il faut la télécharger juste après l’ajout du dépôt.
